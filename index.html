翻譯

自動復原與快捷鍵

隨時按 F8 可重試失敗或未完成的翻譯（不需打開設定）。轉錄中按 F9 可強制重啟辨識，切換來源語言也會直接接續重啟。最近 10 秒內累計 5 秒明顯聲音卻沒有文字進展時，自動重啟；監測只在本機量測音量，不錄音、不播放。連續復原仍無進展時會暫停並提示。長時間沒有人說話時，辨識服務自動結束會立即接續聆聽，不會因靜默而停止轉錄。

往上回看超過視窗高度的 1/3 會暫停自動置底。此時右下角會出現「↑」回到頂端與「↓」回到最新內容；在頂端時只顯示「↓」。「強制置底」可鎖定跟隨（只顯示「↑」），按「↑」會取消鎖定並回到頂端。

翻譯方式

瀏覽器離線翻譯包

免費、在本機執行的瀏覽器內建翻譯。按「開始轉錄」或轉錄中切換語言時，會自動準備目前的語言配對，完成後補翻譯先前的段落。也可在此預先下載：選擇來源及目標語言，每次點擊準備一組。模型由瀏覽器管理，下載後可離線使用，並可供其他網站共用。

    自定義 API

    改用您自己的翻譯或大型語言模型服務。每句辨識完成後，原文會連同提示詞送往下方網址翻譯；費用、品質與資料處理方式由該服務提供者決定。該服務須允許瀏覽器跨來源請求（CORS）。

    Token 安全提醒
    • Token 只保存在這台電腦的這個瀏覽器中，不會傳送到本工具或任何第三方，只在翻譯時直接送往您填寫的 API 網址。
    • 請勿在公用、共用或他人的電腦上輸入 Token；使用完畢請按「清除 Token」。
    • 建議使用權限受限並設有用量上限的金鑰，並定期更換。
    • 逐字稿內容會傳送給該 API 服務，請勿用於不宜外傳的內容。

    可用 {source}、{target} 代表來源與目標語言；要翻譯的句子會另外送出。

    關於使用與保存

    使用 Windows 電腦版 Edge 可獲得較佳體驗。請允許麥克風權限，並透過 HTTPS 或 localhost 開啟網頁。

    語音由瀏覽器的雲端辨識服務處理，必須連網才能使用；翻譯預設使用瀏覽器本機模型，也可在「翻譯方式」改用自定義 API（原文會傳送至該服務）。逐字稿儲存在此網站的本機瀏覽器，清除網站資料也會刪除內容，重要文字請匯出備份。同時開啟多個分頁時，只有一個分頁能轉錄及保存，其他分頁可按「改在此分頁使用」接手。

    切換辨識語言或翻譯語言只影響後續段落。要讓舊段落改用目前的翻譯語言，請按「全文重新翻譯」。複製及匯出只包含已落地文字，不包含辨識中或狀態提示。
