# 聽譯流 EchoFlow

> [!IMPORTANT]
> **請使用 Windows 電腦版 Microsoft Edge 開啟本工具**，以獲得最佳的語音辨識與翻譯效果。其他瀏覽器或裝置可能無法使用部分功能。

聽譯流是一個免費、極輕量的純網頁語音轉錄與翻譯工具：開啟網頁、允許麥克風，就能即時把語音轉成逐字稿並同步翻譯。不需安裝、不需註冊，也沒有後端伺服器或 API 金鑰。

## 使用前須知

- **翻譯品質：** 翻譯預設採用瀏覽器內建的裝置端翻譯模型，以免費、輕量、快速為目標，譯文品質屬堪用程度，適合在一般情境下快速掌握關鍵訊息。本工具**無法取代專業翻譯或人工校對**，請勿將譯文直接用於法律、醫療、合約、正式出版等需要精確內容的場合。
- **自定義 API（選用）：** 可改用您自己的翻譯或大型語言模型 API。此時每句原文都會傳送給該服務，費用與資料處理方式由服務提供者決定。Token 只保存在您這台電腦的瀏覽器中，不會傳送給本工具或任何第三方；**請勿在公用或共用電腦上輸入 Token**，用完請在設定中按「清除 Token」。
- **辨識準確度：** 語音辨識可能因口音、噪音、專有名詞或網路狀況而出錯，重要內容請自行核對。
- **隱私：** 語音辨識由瀏覽器的辨識服務處理，音訊可能傳送至服務供應商，且需要連網。本工具不錄音，也不上傳至任何自建伺服器；逐字稿只保存在您的瀏覽器中。
- **資料保存：** 逐字稿存放在本機瀏覽器，清除網站資料即會刪除。重要內容請隨時用「複製」或「匯出 TXT」備份。
- 本工具依「現狀」免費提供，不對辨識或翻譯結果的正確性負擔任何擔保責任。

## 功能

- 即時語音轉錄：英文、繁體中文、日文、韓文，可在轉錄途中切換語言。
- 即時翻譯：每句辨識完成後立即翻譯，可選擇顯示原文、翻譯或兩者並列。
- 翻譯包自動準備：首次按「開始轉錄」時自動下載所需翻譯模型，下載期間原文照常轉錄，完成後自動補翻譯。
- 兩種翻譯方式（設定 →「翻譯方式」下拉選單切換）：
  - **瀏覽器離線翻譯包**（預設）：免費、在本機執行。
  - **自定義 API**：填入 API 網址、模型、Token 與提示詞，支援 OpenAI 相容（Chat Completions）與 Anthropic（Claude Messages）兩種格式，可先按「測試翻譯」確認設定。服務須允許瀏覽器跨來源請求（CORS）；本機模型服務可用 `http://localhost`。
- 全文重新翻譯：改變目標語言或翻譯方式後，可把舊段落一次重新翻譯。
- 複製與匯出 TXT（UTF-8）。
- 文字外觀：原文與譯文的字型、顏色、大小可分別調整，行距可在緊湊與寬鬆之間調整（預設 1.6 倍）；支援深色模式（點底部「作者：徐承佑」切換）。
- 自動保存與還原：重新整理或重新開啟後自動還原逐字稿；說到一半關閉分頁時，會盡力保留那一句，必要時於重新開啟後提示恢復。
- 自動復原：長時間靜默不會中斷轉錄；偵測到「有聲音卻沒有文字」時自動重新啟動辨識。

## 使用方式

1. 用 Windows 電腦版 Edge 開啟網頁，選擇「辨識語言」與「翻譯語言」。
2. 按「開始轉錄」並允許麥克風權限。第一次使用某組語言時，會先自動下載翻譯包。
3. 辨識中的文字以淡色即時顯示，每句完成後成為一段並附上譯文。
4. 往上捲動回看時會暫停自動捲動；勾選右下角「強制置底」可持續跟隨最新內容。
5. 需要時按「複製」或「匯出 TXT」保存內容。

### 快捷鍵

| 按鍵 | 功能 |
|---|---|
| **F8** | 重試失敗或未完成的翻譯 |
| **F9** | 轉錄中強制重新啟動語音辨識（辨識卡住時使用） |

## 注意事項與限制

- 需透過 HTTPS 或 localhost 開啟；直接雙擊 HTML 檔（`file://`）無法使用麥克風。
- 可用的語言配對、翻譯模型下載與服務狀態，取決於 Edge 版本、裝置、組織管理政策與網路。不支援翻譯時仍可轉錄原文，本工具沒有雲端翻譯備援。
- 翻譯模型下載後可離線翻譯，但語音辨識仍需連網。
- 同一個瀏覽器開啟多個分頁時，只有一個分頁能轉錄與保存，其他分頁只能檢視與匯出，可按「改在此分頁使用」接手。
- 麥克風使用系統預設的輸入裝置。不支援音訊檔匯入、系統聲音擷取、說話者區分及手動編修文字。
- 為偵測「有聲無字」，工具會另外在本機量測麥克風音量（不錄音、不上傳）。少數音效卡驅動以獨佔模式運作時可能衝突，此時會提示並繼續轉錄。

## 部署

本工具是純靜態網頁，無建置步驟，也不依賴 CDN 或外部字型。

**GitHub Pages：** 在儲存庫的 Settings → Pages 選擇 *Deploy from a branch*，分支選 `main`、資料夾選 `/ (root)` 後儲存，等待 GitHub 提供 HTTPS 網址即可。所有資源皆使用相對路徑，支援儲存庫子路徑。

**本機執行**（需 Python 3）：

```powershell
npm start
```

然後開啟 <http://localhost:8080>。沒有 Node.js 時可改用 `python -m http.server 8080 --bind 127.0.0.1`。

網頁執行只需要根目錄的 `index.html`、`styles.css`、`app.js`、`core.js`、`storage.js`、`appearance.js`、`voice-watchdog.js`、`LICENSE` 與 `.nojekyll`；`tests/`、`tools/`、`package.json` 僅供開發測試。

## 開發與測試

```powershell
npm test
npm run test:browser
```

- `npm test`：單元測試，使用 Node.js 內建測試框架，無需安裝套件。
- `npm run test:browser`：以本機 Edge 的獨立測試設定檔執行整合測試，注入模擬的語音與翻譯 API，不使用個人設定檔、不開啟真實麥克風、不下載真實模型。結束後自動關閉 Edge 並清除暫存設定檔；報告與截圖輸出至 `test-results/`（不納入版本控制）。可用環境變數 `EDGE_PATH` 指定 Edge 路徑，`KEEP_EDGE_PROFILE=1` 保留測試設定檔以便除錯。

自動化測試無法取代實際收音驗收，發布前建議以真人實測：麥克風權限、四種語言的辨識與翻譯、首次下載翻譯包、長時間靜默與斷網重連、說到一半關閉分頁後的保存與恢復，以及多分頁接手。

### 程式結構

| 檔案 | 用途 |
|---|---|
| `index.html`、`styles.css` | 單頁介面與外觀 |
| `app.js` | 畫面操作、保存、多分頁協調、快捷鍵 |
| `core.js` | 語音辨識生命週期、離線翻譯與自定義 API 翻譯、逐字稿佇列與匯出 |
| `storage.js` | 本機保存（IndexedDB）、偏好與翻譯設定、復原草稿 |
| `appearance.js` | 文字外觀設定 |
| `voice-watchdog.js` | 音量量測與「有聲無字」偵測 |
